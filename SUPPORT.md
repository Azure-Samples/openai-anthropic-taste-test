# Support

## Issues and questions

Use [GitHub Issues](https://github.com/Azure-Samples/openai-anthropic-taste-test/issues) for sample bugs, feature requests, and questions. Search existing issues first.

Include:

- `azd version` and `dotnet --info`;
- the selected Azure region and model IDs;
- the relevant `azd provision` or application log excerpt with identifiers and tokens redacted;
- whether the failure affects one lane or both;
- browser and operating system for UI issues.
